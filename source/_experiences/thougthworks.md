# Job Description
At ThoughtWorks Brasil Software LTDA, I operated as a Senior Software Engineer acting as Software Architect and Technical Lead across distinct high-impact client engagements, handling both modern cloud microservices architectures and distributed global team leadership.

### Key Responsibilities & Technical Contributions
- **Microservices Architecture & Legacy Modernization:** Designed and guided the architectural blueprint to break down monolithic legacy workflows for a major national automotive parts retailer. Built scalable, decoupled .NET services communicating via REST and asynchronous messaging.
- **GCP Cloud Infrastructure & CI/CD:** Deployed containerized applications using Docker across Google Cloud Platform (GCP), managing deployments on Google Kubernetes Engine (GKE) and serverless workflows with Cloud Run, powered by Cloud Pub/Sub message broker integration and GitHub Actions CI/CD automation.
- **Couchbase Search Engine Optimization:** Solved critical search latency issues (reducing response times from 3–4 minutes down to milliseconds). Diagnosed N+1 queries, unindexed table scans, and memory starvation; created targeted Global Secondary Indexes (GSI), implemented Full-Text Search (FTS), introduced caching layers, and eliminated architectural inconsistencies between development and production database engines.
- **Polyglot System Delivery:** Directed the technical stack balance across Go (for high-throughput, low-latency microservices), .NET (for domain-driven core business APIs and enterprise integrations), and modern TypeScript/React frontends.
- **Global Technical Leadership:** Provided hands-on leadership, cross-timezone team coordination, architectural guidance, and stakeholder communication for a global retail client, ensuring technical standards and delivery reliability.
