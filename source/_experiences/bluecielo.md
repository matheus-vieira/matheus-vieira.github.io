# Job Description
At Bluecielo do Brasil (part of Accruent), I serve as the lead technical reference for frontend architecture, working directly with globally distributed engineering teams across North America, Europe, Asia, and Latin America. My mission is modernizing and unifying the UI/UX architecture of critical enterprise software suites, including Lucernex (telecom and real estate lease management), Siterra (project and site lifecycle management), and Maintenance Connection (computerized maintenance management systems).

### Key Responsibilities & Technical Contributions
- **Legacy Monolith Decoupling:** Migrated legacy server-rendered views tied to VB and Java backends into modern Single Page Applications (SPAs) powered by React and TypeScript, eliminating tightly coupled frontend logic and modernizing user interactions.
- **Cross-Product Architecture & Design Systems:** Defined frontend folder structures, state management lifecycles, and component architectures. Partnered with UX/UI teams to implement pixel-perfect, accessible component hierarchies in Material UI based on Figma design guidelines.
- **Enterprise Data Grid & Component Design:** Engineered a core, cross-product data list component that seamlessly toggles between AG Grid, custom data tables, and card views, standardizing advanced data manipulation (pagination, dynamic filtering, multi-column sorting, and batch item selection).
- **API Contract Alignment:** Co-authored and refined RESTful interface contracts with backend teams, optimizing payload structures and client-side error handling to ensure seamless integration and resilient data flow.
- **Engineering Excellence & AI Adoption:** Participated in setting technical guidelines, conducting in-depth pull request reviews, and mentoring team members on React and TypeScript best practices. Leveraged GitHub Copilot within a Spec-Driven Development framework to accelerate delivery without compromising architectural rigor.
