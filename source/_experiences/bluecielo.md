# Job Description

As a Senior Software Engineer, I modernize legacy frontend systems and help deliver maintainable, user-focused solutions with .NET and React. I lead frontend architecture decisions, collaborate across teams, and apply engineering best practices to improve quality, scalability, and delivery speed.

- Modernize legacy frontend applications by introducing contemporary UI patterns and React-based solutions.
- Lead frontend architecture and development using React, JavaScript, and TypeScript.
- Develop and maintain backend services with C#, .NET, .NET Core, Entity Framework, and Entity Framework Core.
- Apply design patterns, multithreading, automated testing, and unit testing to build reliable software.
- Use GitHub Copilot and Spec-Driven Development to support efficient, well-defined implementation workflows.
- Collaborate with stakeholders and engineering teams to translate business needs into practical technical solutions.
